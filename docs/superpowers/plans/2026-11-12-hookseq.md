# HookSeq Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build HookSeq, a SASRec-style next-track transformer on Yambda with audio, event-type and organic signals. It includes a rigorous EDA → preprocessing pipeline, baselines, ablations, beyond-accuracy evaluation and a Gradio demo. Everything runs on Kaggle's free tier.

**Architecture:** An installable Python package, `hookrec`, with focused modules: data, eda, models, train, eval, demo. The Mac only writes code and runs `pytest` on synthetic data. Thin Kaggle notebooks (`notebooks/kaggle/k0…k5`) clone the repo and call `scripts/*.py`, and they chain stages through Kaggle Datasets. CPU notebooks handle download, EDA, preprocessing and baselines. GPU notebooks handle only transformer training and scoring.

**Tech Stack:** Python ≥3.10, PyTorch 2.x (Kaggle image), Polars ≥1.0, PyArrow, NumPy, SciPy, scikit-learn (PCA), `implicit` (iALS), `huggingface_hub`, PyYAML, matplotlib, Gradio (extra), pytest, ruff.

**Spec:** `docs/superpowers/specs/2026-11-12-hookseq-design.md`. Read it before starting any task.

## Global Constraints

- Training never runs locally. Local work = code + `pytest -q` on synthetic fixtures (CPU, whole suite < 60 s).
- Kaggle design limits:
  - 9 h per session
  - plan around 20 GPU-h/week (of ~30)
  - ≤16 GB RAM
  - 20 GB `/kaggle/working`
  - P100 16 GB or 2×T4
  - fp16 AMP only (no bf16/TF32)
- CPU work (download, EDA, preprocess, MostPop/DecayPop/iALS) must run in CPU-only notebooks.
- Every heavy stage must be resumable/cached. Its outputs go to `/kaggle/working/...` and get saved as Kaggle Datasets for the next stage.
- Split = Yambda Global Temporal Split:
  - train 300 days
  - gap 30 min
  - test 1 day
  - validation = last train day, with the same 30-min gap
  - Timestamps are in 5-second units (`TS_UNIT_SECONDS = 5`).
- "Positive" = listen with `played_ratio_pct ≥ full_threshold` (default 50, final value set by EDA) **or** like.
- Every padding index is 0. Item indices are `1..N`.
- Metrics: NDCG@10/100, Recall@10/100, Coverage@10/100 over the full catalog.
- Every results JSON records the config, git SHA, dataset size and wall time.
- Large data, checkpoints, `*.parquet`, `*.npz`, `*.pt` are git-ignored (already in `.gitignore`).
- Seeds are fixed through `hookrec.utils.seed.set_seed(seed: int)`.
- Commit after every task. Messages use `feat:`/`test:`/`docs:`/`exp:` prefixes.

## Review Focus

1. **Test users with no training history** must get MostPop fallback recommendations, not a crash or silent exclusion. Their count is logged and reported. (Task 9, Task 14)
2. **Test-day items unknown to the vocab** (never seen in train, and possibly no audio) must stay in the ground truth so metrics stay honest. Their share is logged. (Task 9)
3. **A Kaggle session killed mid-save** must never leave a corrupt checkpoint: write to a temp file then `os.replace`, and resume from the last good checkpoint. (Task 14)
4. **Items with no audio embedding and no ID embedding** must still get a finite representation (learned fallback + artist), never NaN. (Task 6, Task 15)
5. **Users whose sequence has no positive targets** (e.g. only skips/dislikes, or length 1) must not produce NaN loss. Batches where every target is ignored contribute zero loss. (Task 7, Task 13)
